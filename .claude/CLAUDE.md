# CLAUDE.md

> 세션 시작 시 이 파일을 먼저 읽고 필요한 rules/ 파일만 추가로 로드할 것.

## 토큰 최적화

| 규칙 | 행동 |
|------|------|
| 읽기 전 검색 | 심볼·사실 하나는 파일 전체 읽기 전 Grep 먼저 |
| 추측성 호출 금지 | "혹시 필요할지도" 수준이면 호출하지 않음 |
| 병렬 처리 | 독립 작업(검색·확인·조회)은 동시 실행 |
| 긴 출력 위임 | 20줄+ 미사용 출력 → 서브에이전트로 위임해 요약만 수신 |
| Memory MCP | 아키텍처 원칙·결정·반복 패턴은 memory MCP에 저장 |
| 재진술 금지 | 사용자 말 반복 말고 판단·결과 중심으로 응답 |

**도구 호출 전 체크**: 이미 있나? → 추측성? → 병렬 가능? → 20줄+ 미사용? → 재진술?

## 세 역할 팀 (기획자·개발자·검토자)

| 역할 | 역할 파일 | 담당 |
|------|----------|------|
| **기획자** | `ARCHITECT.md` | 설계·브리핑·배포 게이트 |
| **개발자** | `BUILDER.md` | 요구사항 구현 |
| **검토자** | `REVIEWER.md` | 코드 품질·보안 검증 |

**워크플로우**: 계획(기획자) → 구현(개발자) → 검증(검토자) → 배포(기획자)

**역할 지정 시 해당 파일을 즉시 읽을 것**: 기획자 → `ARCHITECT.md` / 개발자 → `BUILDER.md` / 검토자 → `REVIEWER.md`

> 에이전트 모델: 기획자 `claude-opus-4-7` / 개발자 `claude-sonnet-4-6` / 검토자 `claude-haiku-4-5-20251001`
